Microsoft 365 Setup

📋 How to get your credentials:

  1. Go to Azure Portal
  2. Navigate to App registrations
  3. Click + New registration
  4. Name your app (e.g., "Pramiti AI Integration")
  5. Copy the Application (client) ID
  6. Copy the Directory (tenant) ID
  7. Go to Certificates & secrets → + New client secret
  8. Copy the secret Value immediately
⚠️ Add this Redirect URI in Azure: http://localhost:8084/api/v1/oauth/callback/microsoft
Format: GUID (e.g., 12345678-abcd-1234-5678-123456789abc)
The secret value from Azure (not the Secret ID)
Format: GUID or "common" for multi-tenant
Use "default" for main organization

Google Workspace Setup

📋 How to get your credentials:

  1. Go to Google Cloud Console
  2. Create a new project or select existing
  3. Enable Gmail API, Drive API, Calendar API
  4. Go to APIs & Services → Credentials
  5. Click + CREATE CREDENTIALS → OAuth client ID
  6. Application type: Web application
  7. Copy the Client ID and Client secret
⚠️ Add this Authorized redirect URI in Google Cloud Console: http://localhost:8084/api/v1/oauth/callback/google
Format: xxx.apps.googleusercontent.com
Usually starts with GOCSPX-
Use "default" for main organization
